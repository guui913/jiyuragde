### 3.2 src/knowledge_base/build_kb.py

**功能**：读取 `data/raw/` 下的所有 .txt 文件，分块、向量化、存入Chroma。

**输入**：
- `data/raw/*.txt` — 领域文档（用户手动放入）

**输出**：
- `data/processed/chunks_metadata.json` — 分块元数据
- `data/processed/chroma_db/` — Chroma持久化向量库

**核心逻辑**：
1. 遍历 `RAW_DATA_DIR` 下所有 .txt 文件
2. 使用 `langchain.text_splitter.RecursiveCharacterTextSplitter` 分块（chunk_size=512, overlap=128）
3. 加载嵌入模型 `bge-small-zh-v1.5`（使用 `sentence-transformers`）
4. 创建 Chroma collection
5. 批量向量化并存入Chroma（batch_size=32）
6. 保存 chunks_metadata.json（每条chunk的来源文件、序号、文本摘要）

**方法签名**：
```python
def build_knowledge_base() -> bool:
    """构建知识库，返回是否成功"""

def add_document(file_path: str) -> bool:
    """添加单个文档到知识库"""
```

### 3.4 src/retrieval/keyword_search.py

**功能**：基于关键词的检索。

**输入**：
- `query: str` — 用户问题
- `chunks: List[dict]` — 所有文档块（从metadata加载）
- `top_k: int`

**输出**：
- `List[dict]` — 排序后的文档块，每个含 `{"text": str, "score": float, "source": str, "chunk_id": str}`

**核心逻辑**：
1. 用 jieba 对 query 分词
2. 使用 BM25Okapi 对所有chunk建临时索引
3. 返回Top-K

### 3.5 src/retrieval/vector_search.py

**输入**：
- `query: str`
- `collection: chromadb.Collection`
- `top_k: int`

**输出**：
- `List[dict]` — 同上格式

**核心逻辑**：
1. 用嵌入模型将query向量化
2. 调用 `collection.query(query_embeddings, n_results=top_k)`
3. 返回结果，score为 `1 - distance` 转余弦相似度

### 3.6 src/retrieval/hybrid_search.py

**功能**：混合检索 + RRF融合。

**输入**：
- `query: str`
- 关键词搜索结果 + 向量搜索结果

**输出**：
- `List[dict]` — Top-K最终结果

**核心逻辑（RRF算法）**：
```
对每个检索结果：
  RRF_score = 1/(K + rank_in_keyword) + 1/(K + rank_in_vector)
  K = 60
按RRF_score降序排列，取Top-K
```

**方法签名**：
```python
def hybrid_search(query: str, keyword_results: List, vector_results: List, top_k: int = FINAL_TOP_K) -> List[dict]:
    """RRF融合两种检索结果"""

def search(query: str, collection, chunks_metadata, top_k=FINAL_TOP_K) -> List[dict]:
    """一站式检索：关键词+向量+融合"""
```

```python
"""
```

## 五、生成代码时的约束

1. **所有导入用绝对导入**（`from src.xxx import yyy`）
2. **所有路径用 `config.PROJECT_ROOT` 拼接**，不硬编码
3. **错误处理**：关键操作（模型加载、文件读取）加 try/except + 中文错误提示
4. **日志**：用 `logging` 模块，INFO级别，输出到控制台
5. **类型注解**：关键函数加类型注解
6. **Chroma collection 名称使用 config.CHROMA_COLLECTION_NAME**
7. **模型加载**：先检测 `torch.cuda.is_available()`，自动选择设备
8. **微调模型加载失败时**：自动降级为基座模型 + 打印警告
9. **Gradio界面**：不使用 `share=True` 默认值

## 八、快速启动检查清单

代码生成完成后，用户应能执行：

```bash

python run.py
```

## 九、常见问题处理

代码中应处理以下情况：

| 场景 | 处理方式 |
|------|----------|
| `data/raw/` 为空 | 打印提示："请先将领域文档（.txt格式）放入 data/raw/ 目录" |
| 嵌入模型下载慢 | 设置 `HF_ENDPOINT=https://hf-mirror.com` 环境变量 |
| CUDA不可用 | 自动切换CPU，打印："未检测到GPU，使用CPU推理（速度较慢）" |
| LoRA adapter不存在 | 降级为基座模型，打印警告 |
| DeepSeek API Key未设置 | 打印："请设置环境变量 DEEPSEEK_API_KEY" |
| Chroma加载失败 | 提示用户先运行 `python run.py --build-kb` |
